CONVERSATE: install as an app on your phone
===========================================
1. Upload this whole folder to any HTTPS static host (it must be HTTPS for the mic and install to work):
   - Netlify Drop: go to app.netlify.com/drop and drag the folder in.
   - Or Cloudflare Pages / GitHub Pages / Vercel.
2. Open the https link on your phone.
   - iPhone (Safari): Share > Add to Home Screen.
   - Android (Chrome): menu > Install app / Add to Home screen.
3. Launch from the home screen icon: it opens full screen, with no browser bar, and works offline.

Voice: the first session asks for microphone access. Use Settings (tap the logo) > Speech to switch to Sample Text.
Listen Back and View Recording play your real recording (kept in memory until you close the app). Turn it off in Settings > Recording.
Updating: re-upload the folder; open the app twice to pick up the new version.
