CONVERSATE: install as an app on your phone
===========================================
1. Upload the CONTENTS of this folder to any HTTPS static host (GitHub Pages, Netlify Drop, Cloudflare Pages).
2. Open the https link on your phone.
   - iPhone (Safari): Share > Add to Home Screen.
   - Android (Chrome): menu > Install app / Add to Home screen.
3. Launch from the home screen icon: full screen, works offline.
Updating: re-upload the files; open the app twice to pick up the new version. If the old layout persists, delete the home-screen icon and add it again.
